# Overview

To learn C++, I decided to write a text adventure game where you play in a post apocalyptic world.

I did this so that I could learn not only the syntax of C++, but also so I could practice using good programming principles of breaking apart big problems into smaller ones.

So, instead of making ugly nested if else loops, I made objects and I made the world a graph that you can explore.
